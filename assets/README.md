# 素材占位规格

这里不放制作素材。请自己准备有权使用的内容：

- 人物 RGBA：保留内部线稿，外轮廓干净；建议大于实际最大画面投影尺寸。补底与可动部件独立保存。
- 环境：与合成画幅相容，有可解释的远中近关系和光向。别用拉伸凑比例。
- 文字：使用自行核对语义的短句，并选择覆盖所需文字的合法字体。
- 音频：使用自有或许可覆盖发布范围的音源；先记录真实帧率和声音长度。
- 序列：请手动保留整套有序编号帧，不仅保留第一帧。本包复制归档与重链接工具明确拒绝序列，避免误把首帧当整段。

第一轮机制练习可以只用 AE 生成的纯色、矩形和你自己写的一句文字，不必找漫画或参考作品。公开演示要另外制作自有素材，不能从原项目随意抽角色图作为封面。
