# 文字需要一个平面设计与时间系统

先区分四种职能：核对后的原句、自己的旁白、歌词、构图字。前三类通常承担理解，构图字可以部分被人物遮住以提供空间和冲击。不要让一段被遮到无法读清的后景巨字承担唯一完整对白。

用实际字形建立系统：标题、短促强调、稳定叙述分别选择字重、字距、尺寸、语言覆盖、基线和留白。引号与文字是一组构图。文本框中心不等于可见墨迹中心；句长改变、横竖排改变时，主字、反射、折射、描边、故障切片、吞字块须一起重定位。

将每句拆成时间阶段：

| 阶段 | 观看任务 | 可用机制 |
|---|---|---|
| 预备/攻击 | 引导眼睛、给语气 | 短切、字形扩张、组级显露、对比变化 |
| 读清 | 实际理解完整句 | 稳定字形、明确前后遮挡、合适的亮暗背景 |
| 余波 | 让意义作用于图像 | 环境继续运动、相机继续、字符暂时停止 |
| 退出 | 交给下一句话/动作 | 实心块吞没、共同裁切、焦点转移 |

一次表述状态可以有实心、描边、反相、错位，不因此多算成几句文案。不要用 2 秒抽样推断一个只有几帧的字形攻击。阅读窗口按实际可见稳定字形量测，再用正常观看验证。

小字号需要重算整组演出。仅改主字大小会留下失配的擦除块、反射或引号；源里的字号改动还可能被相机表达式覆盖。先检查真实驱动关系，只执行一次缩放，避免专项与通用修订叠乘。

明暗判断看每个笔画经过的背景。白字落浅色面、灰字落虚焦散景，不能靠再加整体滤镜解决。必要时让文字短暂接管画面，但图像时钟继续前进，返回的是当前相位，而不是又播放一次人物入场。读区也不能挡住正在承担情绪的眼睛、嘴角或接触动作。

本包文字脚本只演示揭示—读清—吞没的组级几何，是可检查的起点。它没有自动生成好的平面设计，也不能一键获得参考作品的语气、节拍和构图。
