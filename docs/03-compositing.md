# 漫画人物与环境融合：每层解决一个明确问题

建议分组为背景空间、人物基础、人物受光、接触与前景介质、最终光学。先匹配运动和缩放，再补光。整体调色最后做，它不能掩盖人物形体错误或外轮廓污染。

1. **Alpha 与源图。** 白边先内缩/去边色，微小柔化只作用外轮廓。被切掉的身体不可能靠羽化恢复。近看 200–400% 诊断，正常尺寸决定是否合格。
2. **灰阶与环境色。** 背景副本先变成低频色场，再限制到人物 Alpha；让散景图案直接乘到脸上不是反光。保留暗部和墨线，避免人物整身染黄或被压黑。
3. **形体与光向。** 表面背光、发束投影和接触阴影分别设计。脸面按额头、鼻、颧部、下颌转折，衣服按领口和褶皱；大椭圆、左右渐变不等于表面法线。
4. **方向边光。** 只沿真正朝光的发束/肩部控制，不沿全身发一圈游戏立绘光边。内缘小蒙版放大后可能变宽，按最终投影尺寸查。
5. **接触。** 下颌压脖颈、头发压脸、身体重叠提供空间。原格已有接触尽量保留；不把每条轮廓都压成黑边。
6. **材质与空间。** 人物线稿可清楚，远景柔和，中景保留轮廓，近景有遮挡。合成后共享低强度单色颗粒，而不是每层各有一套颗粒。

实际出现过的失败：人物脸上斑块在重做受光之后仍在。原因不是 Alpha，而是前景枝叶纹理覆盖太强。关闭前景介质与环境贡献分别检查，才找到来源。修曝光无法解决这样的层序问题。

阈值提取的是最终亮度：黑发、深衣服、网点和墨线都会被判暗。它可以帮助保留既有明暗，却不能生成新的可信光向。法线估计的 Lambert 点乘也仅表达局部漫反射，不自动产生发束投影与环境遮蔽。生成式重打光可能改五官和泪痕，输出仍须与原画逐项核对；没有实际部署记录时写“候选”，不要写“已批量成功”。

把最终雾、眩光关掉后，画面仍应有清楚的明暗结构。否则光效可能只是把人物问题盖住。流程可推广，具体颜色、强度和蒙版不宜跨素材机械复制。
