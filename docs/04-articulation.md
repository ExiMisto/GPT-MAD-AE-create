# 分体动画：接受做不到的边界

原图可以支持的小幅发梢、衣摆、呼吸，并不意味着它能支持可靠眨眼、大幅转头或新姿态。整张图轻微摆动是摄影或静物运动，不冒称角色演技。

眨眼需要独立的上睫毛、下睫毛、瞳孔/高光、眼白以及补好的皮肤底。闭眼还需要可信的线条或眼皮补画。一次尝试仅靠缩放眼部贴片，产生了异常闭合，最终被否定并撤掉；公开包不把该失败包装成“通用 Live2D 方案”。没有闭眼原画/补底能力时，保留眼神和相机演出比继续堆叠变形更好。

发丝拆分先解决遮挡缝隙：前发掀起时露出的额头、眉毛和后发要补全。发根固定、发梢为主，前后束可以错峰 2–4 帧；这个范围只适合作为试验起点，不是任何帧率/发长都有效的配方。Puppet 或弹簧也不能自动避免网格折叠和发根游走。

实作前记录：层序、枢轴、补底、允许的最大位移、哪些表情线不能碰、镜头何时靠近。动画与阴影/反光共享变形，不让零件移动之后仍受固定原位置的光。正常尺寸与运动极值都要查，不能只看某个静态漂亮时刻。

允许先跳过不可靠动作。停止失败眨眼不是停止成长，而是选择能承担同一观看任务的构图、轻微视线、焦点或摄影，并把未完成能力明确留给后来人。
