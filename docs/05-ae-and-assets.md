# AE 时钟、合成边界与资产归档

## 整数帧先于浮点秒

时间区间采用左闭右开 `[start, end)`，先用 `max(startFrames)`、`min(endFrames)` 做交集，判断长度大于 0，再除以 fps 创建合成。直接用浮点秒相减曾产生不足一帧的伪区间并导致 AE 的 duration 错误。本包 `frame_plan.py` 演示这个最小机制。

预合成的 startTime、inPoint/outPoint、timeStretch 与 time remap 都会改变源时钟。局部脚本写了一个正确帧窗，放进父合成后不一定还在那个全局窗口。对白、吞字块、闪光与摄影的排队时间须核对真实可达层级，而不是只看源场景的注释。

相机拉远、前景移动和光影扫动时，Solid 或外预合成会露出矩形边；羽化了内部蒙版不保证外层画布足够大。检查所有运动极值与父/子坐标变换，不只看中间一张帧。

## 通用配置

`local-config.json` 的路径均可相对配置文件，也可写自己机器的绝对路径；不要提交你的本地配置与报告。`MAD_AFTERFX`、`MAD_AERENDER` 环境变量也可以代替 CLI 的可执行文件参数。

| 字段 | 用途 |
|---|---|
| `source_project` | 只读源工程路径 |
| `master_comp` | 精确主合成名称 |
| `audit_report` | 可达图层素材报告 |
| `archive_manifest` | Python 复制归档产生的映射清单 |
| `archived_project` | 重链接后另存的新工程 |
| `export_project` | 排队导出所用工程；归档后指向 archived_project，不设置则用 source_project |
| `render_project` | 导出排队专用副本，与源工程不同 |
| `output_video` | 最终 MP4；默认禁止覆盖已有文件 |
| `expected_width/height/fps` | 导出前的母版约定，可按作品更改 |
| `type_project` / `type_demo` | 纯原创文本的机制演示 |

## 从真实合成图归档

`audit_project.jsx` 从指定主合成递归遍历图层，**包括 disabled 层**以保留可编辑性，记录文件型 source、proxy 和文字字体名；并将表达式、序列/动态外部依赖标记为人工复核项。不是删除所有“眼下未启用”的东西，也不是只凭二进制路径把全部历史文件当当前主合成的必要素材。

归档默认把每个源文件复制到内容摘要命名的路径，输出 manifest；相同内容只占一份，原件保持原样。文件复制前后会计算 SHA256，验证副本 bytes。本工具明确拒绝图片序列归档，使用者需手动保存整套帧并按序列重新导入；不能把首帧复制当完整归档。字体和插件不是 FootageItem；在删除原目录前另外整理已许可字体、效果插件和表达式文件依赖。

`relink_project.jsx` 按完整源路径映射替换 file source，另外保存 archived_project；缺映射则中止。序列和 PSD/PSB/AI/AEP 等分层文档重链接会明确拒绝，避免把首帧替换成静止图或丢失图层解释。替换会检查尺寸与静止类型，动态源还检查 duration/frameRate；静止图重导可能改变默认 duration，故不把它当动态源时钟失败。它不打开、修改或检查已导出的 MP4。分层文档请使用 AE 原生按层收集/重链接。

## 导出

`queue_export.jsx` 对既有主合成建立独立 render_project，锁定全时域，不重做艺术设计。选择可用 H.264 模板，显式启用音频，并记录模板/设置。`ae_tool.py render` 启动 aerender，等待进程返回并转发日志；不在导出后自动逐帧检查。需要验证时另开明确任务，不能把进程成功包装成审美验收。

通用 JSX 是本包新改写的实现；原项目使用的固定路径脚本机制有实际操作记录，但这份配置化版本尚待实机 AE 验证。不要把 Python 测试通过当成 AE 环境可用或所有输出模板支持相同字段。

## 清理

先归档、确认映射与字体/插件/序列清单，再谈删除。公开工具只给 dry-run，没有任何执行删除接口。原项目曾按 AEP 依赖扫描保住 9 个被旧工程引用的预览文件；后来在用户明确只留最后工程后，改用主合成图归档。保留策略随着任务改变，而不是把每个旧文件都永久保留或一律按版本号删除。
