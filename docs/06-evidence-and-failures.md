# 匿名证据记录：知道什么，以及不知道什么

下表是历史制作中的摘要，不附私有画面和参考视频，也不是可由本包独立复现的视觉证据库。文字记录能帮助后来人避坑，但不能代替亲自观看自己与参考作品的连续视频。

| 事项 | 已有依据 | 状态与范围 |
|---|---|---|
| 整数帧交集避免伪区间 | 旧构建出现 duration 错误，改整数帧后能构建 | 技术机制已实际使用；新 CLI 行为测试 |
| 运动模糊影响标签边界测量 | 无模糊独立诊断保持同曲线后单帧超差消失 | 局部机制已验证；不证明整镜忠实复刻 |
| 图像版式统一导致动态丢失 | 相机、分体、文字阶段被固定画窗替代，受到明确否定 | 失败并恢复；不把所有小画窗都判错 |
| 眨眼贴片异常 | 缺闭眼线/补底的眼部变形不能形成可信闭合 | 失败，撤掉；未获得通用眨眼能力 |
| 环境图乘到面部产生斑块 | 逐层关掉介质后定位到前景枝叶覆盖 | 局部诊断与修正；参数不能批量套用 |
| 灰度阈值生成新阴影 | 黑发、网点与墨线被错误当光照暗面 | 方法解释错误；阈值不是法线恢复 |
| 连续画幅/遮挡/文字演出 | 观察局部参考，制作了分组揭示和取景试片 | 局部执行；没有整片逐帧复刻声明 |
| AI 二分重打光候选 | 阅读/讨论工具与可能工作流 | 未验证部署，不能称工业级保证 |
| 最终导出成功 | 原工程渲染进程正常结束 | 只证明导出执行，不证明参赛审美 |

把每次记录拆成观察、解释、实现假设、执行结果、自己判断、观众反馈。观众喜欢某次改稿不证明单个 Glow 参数普适；完整解码也不证明字能一次读懂。综合改稿可以同时变化多项，但不能把所有收益归给一项处理。

后来人的复刻记录至少应包括：目标连续区间、原片身份/来源、所见时间阶段、未知工程结构、素材与补绘缺口、最小机制、失败形态、输出范围及实际正常速度听看情况。引用录屏时排除暂停、UI 与重复帧；录屏 fps 不冒充原作 fps。

本包保留了匿名失败边界，舍弃了无法合法公开的私有源证据。缺口必须如实说明：它能铺路，却没有把完整竞赛作品或其可重建版权素材一起交出来。
