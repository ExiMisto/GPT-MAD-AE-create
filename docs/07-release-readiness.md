# 发布准备与验证范围

本包没有附参考 MAD。原片、漫画、角色图、歌曲、小说摘抄、VTube 模型、字体二进制、商业插件和原项目 AEP 都未进入公共目录。skill 只快照通用入口与参考方法，去掉项目专属路由；完整用户要求/私聊档案没有复制。

发布准备工具会列文件清单、SHA256、总大小、禁止媒体/工程/大二进制检查、私人绝对路径和秘密样式扫描。结果写入 `RELEASE_CHECK.json` 与 `MANIFEST.json`。这是一轮静态检测，不是法律审查，也不能保证识别所有可能的秘密。不要把扫描通过写成“自动授权所有文件”。

`self_check.py` 对归档副本、同名不同内容、缺失文件、已有目标冲突、序列声明、根目录边界和整数帧做真实临时文件测试。测试不需要版权素材或 AE。

以下仍有明确限制：

- 作者已选择原创公开代码、skill 与文档采用 MIT；第三方作品不适用本许可。
- 第三方仅列 URL 与使用状况，许可没有逐仓库在线重核，均不随包分发。
- 通用化 JSX 没有在新环境 AE 实机验证，字体、模板、表达式和 proxy 需要使用者检查。
- 没有公开成片/原工程/参考片，因此美术结论与逐帧视觉证据不能在这里完整复现。
- 发布命令仅写好供你运行；没有执行 git init、创建远程仓库或 push。

发布前可以补充你有权公开的自制示例，再运行两项检查。按当前状态发布时，请保留上述边界说明。
