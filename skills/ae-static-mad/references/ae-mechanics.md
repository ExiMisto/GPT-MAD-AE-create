# AE 已遇到的实现细节

## 时序与属性

- 歌词区间先做整数帧交集，再除以fps创建预合成。相邻浮点秒数相减可能生成小于一帧的“伪区间”，AE会报 `Comp must have duration`。v31 首次构建失败，改为 `max(startFrames)` / `min(endFrames)` 后通过。
- 已有关键帧的属性不能直接 `setValue`。修改静态值前移除关键帧/表达式，或使用 `setValueAtTime`。添加 Mask/Effect 可能使旧 Property 句柄失效；添加完成后重新获取。
- 蒙版坐标属于图层源空间。源空间受光用原人物副本和局部蒙版，可保留原Alpha；不要往整块不透明Solid上画光后漏出原图矩形。
- 移动窗影/过场光也会露出Solid本身的裁切边，即使蒙版已经羽化。v31的解码末帧发现直线，扩大光影源尺寸并同步平移蒙版坐标后再渲染；检查移动极值，不只看中间漂亮帧。
- 独立动作部件先固定源空间Anchor，再设画面Position。换Anchor不补偿Position会造成跳位。转轴与底图是否接合应在运动前后采样检查。

## 渲染与验证

- 使用独立项目输出实验，保留原工程；当前AE有未保存修改时先保存恢复副本。
- 项目有排队输出时，确认 `render=true`。`aerender -comp` 可能创建额外输出而撞名；已有完整队列时按项目渲染。
- 该机器的 `-mfr OFF` 后仍需数值参数，例如 `-mfr OFF 50`。启动器退出码0不等于子进程渲染完；检查输出、日志和视频帧数。
- Photoshop静帧可由PIL读取转换。透明源PNG做检查时先合成到深色/彩色背景，不凭查看器显示的RGB判定抠图。
- 验证实际导出的MP4尺寸、视频帧数、音轨和时长，再重新解码首尾、切点前后、动作极值和字形读清阶段。音频容器时长可能含AAC填充；视频帧数与整数帧时间线是主依据。
- 无声机制实验明确注明无声，不为通过检测器而加入假音轨。多个有声对照并排播放时只启用一个音轨。
- 采样帧与表达式检查不等于连续人工看片。报告具体检查范围，留下动态节奏、听辨等尚未验证的部分。

## 文字库归属

研究过程中曾调用第三方文字回声表达式；当前公共包不包含该第三方源码。自编切片、蒙版、失焦不能全部统称为第三方插件效果。

AECameraBeatSync适配器用于需要的手摇/漂移；内部测试节律不是测得歌曲BPM。Nautilus、AutomaskHL、DepthFlow和Boxcam未执行时记录为未使用，不因研究过README就写“已接入”。


## 过渡对照与导出恢复

- A/B若声称只变一个过渡，尽量共用人物、背景、文字和音轨预合成，将变体限制在明确帧窗。完整解码后比较窗外画面；编码误差与实际构图差异分开记录。v35过渡前缩略RGB差为0，过渡后只有轻微编码差，支持该对照范围。
- AE桌面执行渲染脚本异常退出时，先确认工程保存与日志，不将空日志/启动器0退出当完成。已有正确输出模块的独立项目可用 `aerender -project ... -rqindex N` 渲染指定队列项，避免另建重名输出；渲染后仍须完整解码核验。不要拿旧项目或其他队列项试错。
- 用近景遮住Alpha撤去时，把人物擦除边界置于前景覆盖宽度内部，并检查整个经过区间。蒙版位于源空间；同屏位置相同不代表源坐标相同。复制前景边光层后移除旧蒙版再加窄条，避免ADD并集意外填亮整块遮挡。

- ExtendScript 还保留一些现代 JavaScript 常能用的名称，如 `short`。以它命名函数会在解析阶段阻断整份脚本，连脚本开头的日志也不会执行。无日志时先排查语法与应用弹窗，不把启动器退出当执行成功。


## 纸页铰链与稀疏检查片

- 两面纸页使用同一3D父级转轴，正反面在局部Z分离；翻到背面后检查墨迹是否镜像露出。封面及其页叠应随同一个轴闭合，终态必须成为单宽书形而非几个展开平面。父级赋值会自动补偿世界变换；明确使用局部轴时可用 `setParentWithJump` 后重设局部Anchor、Position和朝向，检查旋转终态，不仅看关键帧数值。
- 稀疏HOLD时间重映射会使光学时间积分跨越不相邻源时刻。仅关闭最外层运动模糊不一定消除内部摄影的拖影；几何诊断副本可以关闭场景光学积分，但必须标为几何检查，再以完整连续导出验证真实快门和切点。不要拿几何无模糊表冒充正片阶段。
- 硬切跨不同相机位置时，快门相位和多层光学积分可能混入前景位置。单次场景摄影积分、避免包装预合成重复积分，并在实际连续切点前后核验；具体快门不是通用预设。


## 动态道具的实体、图案与镜头一致性

检查书、门、卡片等翻转道具时，追踪同一绑定边、自由边和正反面；终态形状正确与题名正向不足以证明整个实体正确。图案中的压槽、装订线和页口具有方向语义，可能与实际轴相反；相机未绕到另一面时，不用“视角改变”解释换边。用不对称角标做几何诊断，再回到正式纹理检查。

厚度需要连接前后面，不能用平铺的背板条冒充侧面。旋转层的局部深度偏离轴时，根边也会绕圆运动；如果表现柔性连接，应补连续连接结构并检查打开、中间角度和闭合端点。把轴移到闭合面的高度会改变打开端点，必须同时换算所有相关层，不能只修终态。刚性轴、柔性桥和真实体积模型是不同实现，按目标选择；上述来自实际失败诊断，新的修法尚需连续渲染验证，不把单次参数写成通用配方。

## 时间重映射的最后一个关键帧

重写 Time Remapping 时，不能像一般属性一样先删掉全部关键帧。删除最后一个重映射关键帧会自动关闭该层的重映射，原 Property 随即隐藏，下一次 setValueAtTime 可能失败。保留或先建立一个新首关键帧，再删其余旧关键帧，最后写新序列；仍检查源时间、入出点和连续输出。这个修正在实际三段工程构建中验证。预合成内使用静态 PNG 不代表预合成本身不能重映射；遇到隐藏属性先查具体属性路径与父级状态，不通过撤掉时间演出来消除报错。

## Shape 蒙版与吞字块的局部坐标

蒙版的顶点在被遮图层的局部坐标中，不是合成坐标。Shape矩形通常以局部原点为中心，移动到合成中心不改变这点；若把整个合成的四角直接写入蒙版，可能只遮住一个象限。绘图前记录Shape路径、Anchor、Position及父级；简单平移可以减去图层中心，有缩放、旋转或父级时按实际逆变换换算，不能沿用减中心的捷径。

实心吞字块同样检查支点：路径居中生成时，左侧展开需要本地左边作为Anchor，Position放在实际文字左边且垂直居中。若图层的构造函数接受的是左上角，但内部生成居中路径，不要在调用后再次把Position当左上角。先核满幅读区和展开端点，再看快动画；错误的坐标不能用更快的遮挡隐藏。

脚本日志声称修复，不证明交付所读工程已保存同一状态。一次实际后段输出仍出现角落色块，重新读独立工程后发现其稳定蒙版仍使用合成四角。修正保存为新文件、重新打开核验关键帧，再确认渲染源与已核文件相同后，实际输出才消除错误；未确定的覆盖或写入原因不补造结论。多份同名版本与独立渲染进程并存时，检查具体输入文件、保存状态和输出来源，不能拿另一段的修复通过外推全片。

本经验只证明该几何失败的修正；不是新的审美预设。修复后仍需核实际输出与切点。读字底板的尺寸按可见墨迹和动画极值决定，源预合成的空白padding不能直接成为黑底的长度；稳定字形无位移时可只截去多余空块，保护原摄影。更换完整句子时同步清点依赖旧句的擦除块，避免文字已撤而旧块孤立返场。
