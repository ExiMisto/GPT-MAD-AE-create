# 鉴赏与审美判断

这是一套看作品并形成意见的方法，不是统一所有 MAD 的风格评分表。可只深入当前最关键的问题。

## 先看段落，再拆镜头

具备连续视频时，先正常速度看一个完整情绪段，记住第一眼落点、惊讶或失去兴趣的位置，再回看镜头前后。静帧精美不保证接在这里有效；单帧简单也可能是段落必需的停顿。只有采样预览时，明确局限，不用推测填补连续观看。

| 关系 | 要问的具体问题 | 常见误判 |
| --- | --- | --- |
| 内容与形式 | 谁的处境在改变？意识流的意象/规则有什么发展？ | 剧情介绍堆成说明字幕；只剩漂亮人物轮换 |
| 构图与观看路径 | 脸、手、字、空场谁先被看见，谁接走视线？ | 素材平均摆开；为展示全图牺牲情绪特写 |
| 文字与时间 | 语气、尺度、出现/停留/离开是否符合这一刻？ | 弹入即算动效；大字即冲击；小字即高级 |
| 光与空间 | 有没有体积、遮挡、距离、共同光源？ | 染色或全轮廓发光代替空间；全片过曝 |
| 动作与摄影 | 感到的是角色动作、相机观察还是装饰漂浮？ | 每层微晃；无目标推近；保护素材成为不动的借口 |
| 镜头与段落 | 切换交接了什么？密度和情绪有起伏吗？ | 每镜前后重置；所有重拍用同一种冲击 |

不必每部填满六项。指出真正决定该片个性的两三处，并写出理由。

## 表达自己的判断

把“很有张力”写到可以争论的程度：目标是什么；可见证据是什么；它使我怎样观看；得到什么、牺牲什么。提出删减、延长、改变焦点等替代方案，比较会损失的优点。不能把“不偏爱这个风格”伪装成技术缺陷。

可以欣赏一个作品的空间构建，同时反对把密集光轨移植进安静对话；可以喜欢大胆切字，同时指出当前样稿的关键笔画不足以辨认。完整句子不必每帧可读，但要分清表演字、语义句与纹理字，明确观众何时应该读到什么。

## 当前倾向与修正条件

- 倾向关系明确的构图：眼神、接触、距离和遮挡决定人物位置。纯图形段落可让字形和负空间主导。剧情要求割裂时，刻意不连贯也可成立，不能机械纠正成平衡海报。
- 倾向让一次显著变化带来新的画面状态。纯闪烁和碎屑若只遮盖信息，通常不如明确的撤图、焦点交换或尺度转折。节奏型作品中短促视觉打击本身可以是任务。
- 倾向让安静镜头接住前一个动作或表情。空镜不因“留白”天然有情绪；需要具体前因或可识别意象。
- 倾向保留原画独有的表情与笔触。大幅改造并非禁忌，关键是改造后仍有表达。遇到以变形为语言的作品，按其自身规则评价。

这些不是审美终点。研究新作时主动寻找挑战当前偏好的例子；有充分观察才更新，不为了标新立异反对旧意见。

## 让学习可迁移

有效记录：证据范围与定位 → 判断及代价 → 机制的可能解释 → 可实施的重建 → 换题材仍成立的关系 → 自己当前作品要改的具体处 → 实践结果。归纳机制时，拿掉角色名、曲名和固定颜色后仍应说得通。

历史案例只支持已观察的范围：

- 《随心而行的日常》公开预览中，人物、近景与方向性亮区共同延展漫画空间。学的是画幅内外空间连续；不能证明某个特定扩图工具有效。
- 《小镇》预览有面部特写、黑场短句与明显密度差。我的兴趣在撤除信息后的阅读重量；它在原片节奏上如何成立仍需连续观看。不可声称已学会原作切点。
- 本地一次文字试作只让三条窄带轻微错位，用户未感到明确冲击。我认同事件作用面积过小，准备比较空间共同响应；不证明更大字、更大位移永远更好。
- 一次手部近景承诺“伸出”却只旋转约三度，结果像漂浮。问题是意图与姿态变化不匹配；不能归纳为所有手必须大摆动。

更多历史工程证据按需见 [experiment-evidence.md](experiment-evidence.md)。那里是案例，不是新作品必须遵守的配方。

## 忠实复刻与从局部到全片的退步检查

用户要求完全复刻时，先保持参考的文本、构图、画幅和时间过程，重建可编辑图层并对齐连续帧；换题材、换字或重新定时是之后的改编。逐帧核对入场、强调、读清、退场以及前后镜交接，不以主帧相似或调用了效果库判通过。缺原字库/原图/背景时列出真实差异，未补齐不能自行改称“机制迁移”后宣布复刻合格。录屏重复帧、UI和压缩不是作者动画设计；原工程未知时仍可重建可见结果，但不虚报作者工具。

扩大制作范围前，对照实际已认可段落的构图、人物蒙版、受光、字的时间结构和接点；重复编号或复用素材不等于继承认可。通用代码宜承担导入、保存、审计等重复操作；若同一个构图/光照/运动模板被赋予许多不同情绪，先检查它是否抹掉差别。失败时保留时间基准和可靠素材，允许重做美术与剪辑，而非继续在不成立的构图上堆效果。

自评要能否定自己的实现：例如短暂显字后的长持图、统一比例阴影冒充结构受光、矩形切片冒充人物退出、微推拉冒充摄影。用实际输出与参考的连续阶段指出损失，再修改；再次抄写“要有张力”不会自动提高制作。上述为制作退步后的纠正原则，不是已经经新复刻证明成功的经验。

## 审核当前输出，不复读旧反馈

先锁定实际视频的版本、时域和镜号映射，再把历史问题分成仍存在、已改变、已解决和证据不足。转场已经存在但接力无效，与完全没有转场是不同诊断；表情前已增加缓冲，与直接相邻是不同顺序。新批评要指向当前输出，不能用旧反馈替代重看。

宏观采样用于找弱段，关键差异再加密到足以辨认阶段。例如整组同步淡出不能写成逐个人退出，整图放大不能写成手臂伸出，字短暂裁切不能写成整句缺失。层名、预设和工程结构提供实现线索，不证明观看者感到相应动作；静帧也不裁定正常速度的流畅与阅读。

区分同源取景、改变意义的回返、无任务的再放，以及不同素材被同一公式处理。前两种可发展事件；最后一种即使文件各不相同，也会让全片单调。审核同时指出值得保留的关系链，弱段从观看任务重建，好的段落做针对性精修。统一语言不等于统一字号、滤镜、振幅和色温。

写修改方案时分别列可见事实、自己的取舍、下一版实现及未解决的素材条件。修复脚本、结构校验和成片观看各自保留结果；尚未渲染的做法仍为假设。来自一次全片静帧／加密阶段审核的纠错，尚不能据此宣称节奏或综合质量提高。

## 对标目标高于消除错误

用户明确以优秀成片为目标时，“无穿帮、字能读、有转场”只完成基础检查。比较具体参考的场景组织、主次、明暗、动画阶段与退出：它做成了什么，当前输出少了什么，要改成怎样的观看过程。保留有价值的内容依据，不自动保留当前的演出。两种题材不必画面一样，但比较必须有实际可见的对象与阶段，不能只说参考高级。

素材局限是设计与制作条件，需要拆层补底、保持接触、补绘／取得支持姿态、改变摄影或改由物件与文字承担形式任务。选择应保住核心表情与内容，并在完整动画里检查收益；不得把缺姿态写成“已动作”，也不把素材问题列成免改理由。艺术性、叙事性或节奏表现的主攻由当前作品意图决定，不把一次项目选择提升为所有 MAD 的方向。
