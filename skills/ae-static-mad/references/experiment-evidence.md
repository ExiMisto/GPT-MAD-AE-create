# 匿名实验记录与验证边界

此公共快照没有复制私有实验工程、用户评审全文或原素材。详见公共文档 [失败摘要](../../../docs/06-evidence-and-failures.md)。

曾实际遇到：窄椭圆衬底像污痕，重复主句争抢阅读，微弱动作正常观看不可感知，缺闭眼原画的变形无法成为可信眨眼。技术成功、观众偏好与隔离变量的机制证明分别记录；没有证据的“更舒服”不自动归因于光扫或单个参数。

未来实验应自建合法素材，记录原假设、作用机制、变化范围、执行结果、正常速度观察和保留的失败版本。静帧比较不能测试阅读顺序，完整解码不能证明情绪成立；缺少公开源证据时如实说明，不能把摘要当原实验的独立复现。
