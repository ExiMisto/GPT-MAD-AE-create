# 学习记录的维护

skill保存跨作品的判断和操作方法，项目入口保存当前约束、最新反馈与版本；逐帧观察、实验、历史失败和参数留在档案／项目research。一个项目的配色、人物、固定对白和版本不写成通用规则。

长档案不再每轮整本重读。原必读入口每轮完整读取；具体任务按索引读取相关skill参考和项目记录。新用户修改入口时读原文件，不使用旧快照替代。详细记录追加档案，入口只更新当前有效要求和路由，避免无限增长。

更新前保存原文和SHA256，保留用户原句与来源。整理时分为观察、实现假设、已试结果、自己判断、用户反馈；被否定的实验不能作为成功配方。历史要求被后续指令覆盖时明确标记，不删除失败证据。

将反馈转成会改变下一次决策的方法：例如“背景取色不能代替接触阴影”“相机拉远需检查预合成边界”，而非重复“要更高级”“要努力”。给出适用条件和失效表现；未验证设想保留状态，不增加硬性普遍规则。

每次方法沉淀检查：另一个作品是否仍能使用？会不会要求固定颜色、插件或镜数？是否与已有参考重复？新增详细内容放条件参考，由skill入口提供路由。每轮实际验证和用户反馈留在项目，只有改变通用判断时才更新skill。
